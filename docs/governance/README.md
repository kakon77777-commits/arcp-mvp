## Adjacent AGIRight authority work

AREC complements, rather than replaces:

- `AGIRIGHT_From_Crawler_Rights_to_Agent_Authority_v0.1.md`
- AARS — Agent Action Rights Spectrum
- AADP — Agent Authority & Delegation Protocol

Conceptual split:

```text
AARS = what actions an Agent may perform outwardly
AADP = who may delegate which authority to an Agent
AREC = who has what authority over the Agent's own identity, Residence, infrastructure relations, and continuity
```

Future reciprocal references should be added in AGIRight when those documents are next revised.
